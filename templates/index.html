Secure patient records, watched for unusual access

MediShield AI is a prototype electronic health record system. It keeps a log of everything staff do, learns what a normal day looks like for each role, and raises an alert when someone's day looks different.

{% if g.user %} Go to dashboard {% else %} Log in {% endif %}

How it works

1

Every action is logged

Logins, searches, record views and edits are written to an audit log by the server.

2

Each role has its own baseline

A model learns the usual activity of doctors, nurses, receptionists and administrators.

3

Unusual days become alerts

An administrator reads the reasons, investigates and marks each alert as reviewed.

What each role can do

RoleAccess
doctorSearch patients, read full records, edit patients, add and edit medical records
nurseSearch patients, read full records, add nursing notes
receptionistSee basic patient details only, register patients, update phone and address
adminManage oversight: users, audit logs and alerts. No access to patient data
